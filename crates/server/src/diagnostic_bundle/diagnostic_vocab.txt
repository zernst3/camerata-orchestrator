# The words a diagnostic bundle's text skeleton keeps (see `sanitize::text_skeleton`).
#
# Every other word of an engine or provider message becomes `_`. A word belongs here only when it
# is an engine or provider error word that says nothing about a client: no product, person, place
# or domain noun. Keep it lower case, one word per line. A word added here can appear in a bundle
# whenever a message holds it, so when in doubt, leave it out: an unknown word costs a developer a
# guess, a client word in a bundle costs the client's trust.
