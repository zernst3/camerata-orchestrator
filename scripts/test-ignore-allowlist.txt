# Tests that may be #[ignore]d. Read by scripts/check-test-ignores.sh, which fails on any
# ignored test in a tracked .rs file that is not named here.
#
# A test that exposes a bug is never ignored: it stays red until the fix lands, and a red
# branch does not merge. An ignore is allowed only for an on-demand harness, in one of these
# categories:
#   perf, live network, keychain, real tokens, outside data, baseline re-approval,
#   external tool, wall time (run by the gate)
# "wall time (run by the gate)" is for a correctness test that is ignored only because it is
# slow; the gate runs it as its own step.
#
# Format: one entry per line, `path::fn_name  # category: short reason`.
# Blank lines and lines starting with `#` are comments.
